# Bundled fonts

Embedded in the private PDF print template; no network requests during rendering.
Downloaded from the Google Fonts repository on 2026-11-13:

- Sora variable: https://github.com/google/fonts/tree/main/ofl/sora
- IBM Plex Mono Regular: https://github.com/google/fonts/tree/main/ofl/ibmplexmono
- Noto Emoji variable: https://github.com/google/fonts/tree/main/ofl/notoemoji

The accompanying OFL files retain each font's copyright and license notices.
The filenames in this directory are local aliases; the font data is unmodified.
